## 📊 Complexity Awareness

One of the important parts of this challenge was learning to think about:

```text
Time Complexity
Space Complexity
```

For example:

```text
O(1)
O(log n)
O(n)
O(n log n)
O(n²)
```

I also started comparing different approaches to the same problem.

For example:

```text
Brute Force
    ↓
Working Solution
    ↓
Analyze Complexity
    ↓
Find Better Approach
    ↓
Optimize
```

## 🔥 Day 30 — Longest Consecutive Sequence

Example:

```text
Input:
[100, 4, 200, 1, 3, 2]

Sorted:
[1, 2, 3, 4, 100, 200]

Longest consecutive sequence:
1, 2, 3, 4

Output:
4
```

My Day 30 approach:

```text
1. Sort the array
2. Traverse the sorted array
3. Detect consecutive numbers
4. Track the current sequence
5. Track the longest sequence
6. Return its length
```

Current approach:

```text
Time Complexity: O(n²)
Space Complexity: O(n)
```

Optimization can be explored later using a `set` for an **O(n)** solution.

## 💡 What I Learned

This challenge taught me that solving problems is not just about knowing syntax.

The important process is:

```text
Understand the problem
        ↓
Think about the logic
        ↓
Write my own solution
        ↓
Test it
        ↓
Find mistakes
        ↓
Analyze complexity
        ↓
Learn a better approach
```

I intentionally focused on **writing my own solution first**, even when it wasn't the most optimal implementation.
